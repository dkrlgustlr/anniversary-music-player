# Anniversary Music Player — HTML 버전

별도 설치나 빌드 없이 실행되는 순수 HTML·CSS·JavaScript 사이트입니다.
모바일 화면에서는 브라우저 여백 없이 가로·세로 전체 영역을 채우도록 구성되어 있습니다.

## 실행

`index.html` 파일을 더블 클릭하면 바로 열립니다. 브라우저 정책상 음악은 가운데 재생 버튼을 누른 뒤 시작됩니다.

## GitHub Pages에 올리기

이 폴더 안의 파일과 폴더를 그대로 GitHub 저장소 최상위에 업로드하세요.

- `index.html`
- `styles.css`
- `script.js`
- `images/`
- `audio/`

그다음 저장소의 **Settings → Pages → Deploy from a branch**에서 `main` 브랜치와 `/ (root)`를 선택하면 됩니다.

## 내용 수정

- 제목과 문구: `index.html`
- 색상과 화면 디자인: `styles.css`
- 재생 기능: `script.js`
- 배경 이미지: `images/anniversary-main.png`
- 음원: `audio/anniversary-rap.mp3`
